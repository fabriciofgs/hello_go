# hello_go
To run this simple app:
1. Copy the main.go to a new directory
2. Open the terminal on that directory
3. Type: go mod init "name of the project"        Usually is github.com/your_user/name_of_the_project
4. Type: go mod tidy       This will download the required gin module and the dependencies of the gin module
5. type: go run main.go     This will build and run the project
6. On any browser access: localhost:8080/hello or 127.0.0.1:8080/hello
